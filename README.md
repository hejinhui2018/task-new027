# PackProof · 多语言包装版面验收台

包装团队同时维护同一款产品的中、英、德三套包装文案。PackProof 在浏览器本地按**真实毫米区域**（正面 / 侧面 / 背面）预演排版结果，依据**实际文字测量**选择可用排版方案，并在失败时指出**是哪段文字、触犯了哪条限制**——而不是只亮红灯。

技术栈：React 18 + TypeScript + Vite，全部在浏览器本地运行，无任何服务端依赖。

## 运行方式

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（默认 http://localhost:5173）
npm test           # 运行全部测试（vitest，38 个用例）
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run preview    # 预览生产构建产物
```

要求 Node.js ≥ 18。

## 功能一览

- **毫米级版面预览**：正面 120×80mm、侧面 40×80mm、背面 120×80mm，每个排版区域按真实尺寸绘制，文字按引擎计算出的字号/行距逐行渲染，所见即引擎所得。
- **语言与版本切换**：中文 / English / Deutsch 三套文案，v1.3 现行版 与 v2.0 北欧上市改版 两个版本，切换后立即重排。
- **可调约束**：每个区域可单独设置允许的字体、字号范围（pt）、行距范围（倍数）。
- **候选方案选择**：按「字号从大到小 → 行距从小到大 → 字体按列表顺序」枚举候选，取第一个能完整放下的方案；全部放不下时回退到缺口最小的方案并报告。
- **四类违规诊断**（每条都写明哪段文字、哪条限制、缺多少毫米）：
  - `溢出`：文案在最小字号/最小行距下仍超出区域高度；
  - `越界`：存在不可断行的词（如德语长复合词）超过区域可用宽度；
  - `顺序错误`：阅读顺序编号与面板上的物理上下位置矛盾；
  - `不可拆分声明`：强制声明必须完整落在同一区域，禁止跨区拆分，放不下时明确报警。
- **改版对比**：选择对比基准后并排渲染两个版本的同一面板，并按「仅当前版 / 仅对比版 / 共有」分组对比问题清单。
- **撤销 / 重做**：所有编辑（文案、约束、切换）进入历史栈，Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z 可用；逐字输入自动合并为一步。
- **刷新恢复**：状态自动写入 localStorage，刷新后原样恢复；存档损坏或结构过期时安全回退初始状态。
- **一键重置**：清除本地修改与存档，恢复出厂数据。
- **确定性**：排版引擎是纯函数，同一输入重复计算结果完全一致（有测试保障）。

## 内置场景：北欧上市改版（v2.0）

切换到「v2.0 北欧上市改版」后，德语和英语暴露**不同**的冲突，中文作为对照组全部通过：

| 语言 | 暴露问题 |
| --- | --- |
|  Deutsch | 背面「强制警示声明」更换为北欧长版强制声明 → **不可拆分声明**放不下声明区；侧面储存说明引入超长复合词 `Kühllagerungstemperaturgrenzwerte` → **越界** |
|  English | 正面卖点声明加长 → **溢出**；新增的北欧处置说明被放进面板顶部的食用方法区 → **阅读顺序错误** |
|  中文 | 无违规（对照组） |

v1.3 现行版三种语言全部通过，可用于「改版前后」对比。

## 使用说明

1. 顶栏切换语言与文案版本；「改版对比」下拉选择基准版本即可并排对比。
2. 左侧面板标签切换 正面 / 侧面 / 背面；点击区域可在右侧「约束」页调整该区域的字体/字号/行距。
3. 右侧「文案」页直接编辑当前语言+版本的每一段文字，改动**立即重排**。
4. 右侧「问题」页列出全部违规，点击条目可在版面中定位对应区域。
5. 顶栏右侧按钮：撤销 / 重做 / 重置；问题计数徽标实时反映当前验收状态。

## 架构

```
src/
  types.ts               领域类型（面板/区域/约束/文案块/版本）
  data/product.ts        内置产品数据：毫米几何 + 三语言 × 两版本文案
  engine/
    measurer.ts          Measurer 接口；CanvasMeasurer（浏览器真实测量）/ MockMeasurer（字宽表，测试用）
    wrap.ts              分词（拉丁词/连字符/CJK 逐字）+ 贪心换行
    layout.ts            候选方案枚举与选择、区域排版、四类违规诊断、违规对比
  state/
    store.ts             纯函数：reducer、历史栈（撤销/重做/合并）、序列化与校验
    useWorkspace.ts      React hook：历史栈 + localStorage 持久化 + 重置
  components/            TopBar / PanelView / ViolationsPanel / CopyEditor / ConstraintsEditor
  App.tsx                组合与接线（layout 是 state 的纯函数，编辑即重排）
```

**确定性设计**：引擎不依赖 `Date.now` / `Math.random`；候选枚举顺序固定；失败回退按（横向越界量 → 纵向溢出量 → 候选顺序）字典序比较；浮点比较带 0.01mm 容差。

**测量抽象**：浏览器中用 Canvas 2D `measureText` 做真实文字测量；测试与无 Canvas 环境注入基于字宽表的 `MockMeasurer`，两者对同一输入均保证确定性输出。
