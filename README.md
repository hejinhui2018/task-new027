# PackProof · 多语言包装版面验收台

面向包装团队的本地化验收工具：同一款产品的**中 / 英 / 德**三套包装文案，按**正面 / 侧面 / 背面**的真实毫米区域排版，依据**实际文字测量**自动选择可用排版方案，并把验收失败原因讲清楚——是哪段文字、触犯了哪条限制、差多少毫米，而不是只给红色警告。

全部计算在浏览器本地完成，无需任何后端。

## 运行方式

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（默认 http://localhost:5173）
npm test           # 运行全部测试（vitest，40 个用例）
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run preview    # 预览生产构建结果
```

要求 Node.js ≥ 18（开发使用 Node 22 验证）。

## 功能一览

- **毫米级版面预览**：三个面版按真实毫米渲染，区域边界即印刷边界；超出区域的内容直接画出界外并标红。
- **语言 / 版本切换**：中、英、德 × 基准版 v1.0、北欧上市改版，随时切换。
- **排版约束可调**：允许的字体（无衬线/衬线/等宽）、字号范围（pt）、行距范围（×字号），修改后立即重排。
- **自动方案选择**：系统在约束允许的全部「字号 × 字体 × 行距」组合中，按测量结果选出第一个完全满足的方案（字号大优先、字体按允许顺序、行距宽松优先）；每个区域标注实际采用的方案。
- **四类违规，条条有据**：
  | 违规 | 含义 | 说明包含 |
  |---|---|---|
  | 溢出 OVERFLOW | 内容总高超过区域高 | 区块名、需要/可用毫米数、超出量 |
  | 越界 OUT_OF_BOUNDS | 不可断行的词超过区域宽 | 具体的词、实测宽度、区域宽度 |
  | 顺序错误 ORDER | 区域位置与规定阅读顺序冲突 | 冲突的两个区块、规定位次 |
  | 声明拆分 ATOMIC_SPLIT | 不可拆分声明放不下、又不能跨区拆分 | 声明原文、需要/剩余毫米数 |
- **编辑即重排**：文案编辑、约束调整都实时重新排版。
- **对比改版前后**：并排渲染基准版与北欧改版，违规清单标注「新增 / 已解决 / 持续」。
- **撤销 / 重做**：Ctrl/⌘+Z、Ctrl/⌘+Shift+Z（或按钮），连续击键合并为一步。
- **刷新恢复**：所有状态写入 localStorage，刷新后原样恢复；存储损坏时安全回退到预设。
- **一键重置**：恢复内置预设文案与约束。
- **确定性**：排版引擎是纯函数，同一输入重复计算结果完全一致（有测试保证）。

## 内置场景：北欧上市改版

预设复现了团队遇到的真实事故，且**德语与英语暴露的是不同冲突**：

- **德语（背面）**：警示语换成更长的法规文本后多出一行（溢出）；编辑把放不下的强制声明挪到过小的「认证区」——声明不可拆分（ATOMIC_SPLIT），且声明排到储存说明之后，阅读顺序被打乱（ORDER）。
- **英语（正面 + 侧面）**：营销标语变长，正面标语区溢出（OVERFLOW）；联系信息里新增的追溯链接是不可断行的长词，超出侧面区域宽度（OUT_OF_BOUNDS）。
- **中文**：两版均通过，作为绿色对照。

在「文案编辑」里把德语警示语改短、或在「排版约束」里放宽字号下限，可以实时看到违规消失。

## 目录结构

```
src/
  engine/           纯函数排版引擎（不依赖 React/DOM）
    types.ts        全部类型定义
    measure.ts      文字测量：canvas 实测（浏览器）+ 确定性表格测量器（测试）
    wrap.ts         换行：拉丁按词、CJK 逐字、超宽词检测
    layout.ts       候选方案枚举与选择、区域排版、四类违规校验、版本对比
    presets.ts      面版毫米区域、文案区块、三语两版文案、默认约束
  state/
    store.ts        reducer + 撤销/重做历史（连续编辑合并）
    persistence.ts  localStorage 读写、损坏回退、约束校验（存储可注入）
  components/       TopBar / PanelView / PanelsRow / ViolationsPanel /
                    CopyEditor / ConstraintsPanel / CompareView / SidePanel
  App.tsx           组合状态与视图，编辑后立即重排
tests/              六组 vitest 测试（node 环境，表格测量器）
```

## 实现要点

- **测量一致性**：浏览器端用 canvas `measureText` 测量，字体栈与渲染完全一致；测试端用确定性表格测量器（CJK=1em、拉丁≈0.52em 等），保证无浏览器环境也能得到稳定结果。
- **单位**：区域用毫米，字号用 pt（1pt = 25.4/72 mm），行高 = 字号 × 行距倍数；渲染时按 96dpi 换算为 CSS 像素。
- **候选方案**：枚举「字号 0.5pt 步进 × 字体 × 行距 0.1 步进」，整数步进避免浮点漂移；第一个同时满足高度与宽度约束的方案胜出，全部失败时回退最小方案并逐条报告原因。
- **阅读顺序**：区块的 `order` 字段是规定顺序，实际顺序按区域空间位置读出，两者第一个不一致处即报错并指出双方。
- **不可拆分声明**：原子区块必须完整落在单个区域内，放不下即报「声明拆分」，绝不跨区续排。
